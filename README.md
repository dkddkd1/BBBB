# 비플페이 지도

비플페이로 결제할 수 있는 가맹점을 지도에서 찾아볼 수 있는 웹 서비스입니다.

> 상태: 기획 단계 (2026-11-03 작성)

## 1. 목표

- 내 주변의 비플페이 사용 가능 가맹점을 지도에서 바로 찾는다.
- 업종, 지역, 키워드로 가맹점을 검색하고 걸러 본다.
- 모바일에서 쓰기 편하게 만든다.

## 2. 주요 기능

### MVP (1차)
- [ ] 지도에 가맹점 마커 표시 (마커가 많으면 클러스터링)
- [ ] 현재 위치 기준으로 주변 가맹점 보기
- [ ] 가맹점 이름/주소 검색
- [ ] 업종 카테고리 필터 (음식점, 카페, 편의점, 병원/약국 등)
- [ ] 마커 클릭 시 상세 정보 (상호명, 주소, 업종, 전화번호)
- [ ] 목록 보기 (지도 화면과 전환)

### 2차 (추후)
- [ ] 즐겨찾기
- [ ] 길찾기 연결 (카카오맵/네이버지도 앱으로 넘기기)
- [ ] 가맹점 정보 오류 제보
- [ ] 지역별 가맹점 통계

## 9. 실행 방법

### 구성

```
[사용자 브라우저] ── [Vercel: Next.js + OpenStreetMap(Leaflet) + Gemini 검색 API] ── [Supabase]
                                                                                    │ 수집 대기열
                                                    [내 PC: worker/] ───────────────┘
                                                      ├ aside → 네이버지도: 구획 경계 폴리곤
                                                      └ 공공데이터포털 소상공인 상가정보: 폴리곤 안 식당
```

- 사용자가 지역을 입력하면 Supabase `regions`에 수집 요청이 쌓입니다. 내 PC의 워커가 aside로 네이버지도에서 구획 폴리곤을 가져오고, 그 폴리곤으로 소상공인 상가정보 API(`storeListInPolygon`, 음식 대분류 I2)를 조회해 식당을 저장합니다. 주점(I211)과 카페(I212)는 뺍니다.
- 네이버 폴리곤을 못 찾으면 OpenStreetMap 경계로 대신합니다.
- 식당 클릭 → 비플페이 가능(형광 테두리 깜빡임) / 불가능(회색). 최신 응답이 모든 사용자 화면에 실시간으로 반영됩니다.
- 로그인 없이 누구나 사용합니다. 쓰기는 `request_region`, `set_bplpay` DB 함수로만 허용합니다.

### 1. Supabase
1. 새 프로젝트를 만들고 SQL Editor에서 [supabase/schema.sql](supabase/schema.sql)을 실행합니다.
2. Project Settings > API Keys에서 URL, publishable key(`sb_publishable_...`), secret key(`sb_secret_...`)를 복사합니다.

### 2. 공공데이터포털 인증키
[소상공인시장진흥공단_상가(상권)정보](https://www.data.go.kr/data/15012005/openapi.do)에서 활용신청을 하면 인증키가 바로 발급됩니다. 키가 실제로 동작하기까지 1시간 정도 걸릴 수 있습니다.

### 3. 환경 변수
`.env.example`을 `.env.local`로 복사해 값을 채웁니다.

### 4. 웹 실행
```bash
npm install
npm run dev
```
- http://localhost:3000 : 서비스
- http://localhost:3000/demo : 키 없이 마커 표시만 확인하는 데모

### 5. 수집 워커 (내 PC)
aside 앱이 켜져 있고 aside CLI가 설치·로그인되어 있어야 합니다.
```bash
npm run worker
```
특정 구획 하나만 바로 수집하려면 `npm run worker -- 연남동`. aside 원본 응답은 `worker/debug/`에 저장됩니다.

### 6. Vercel 배포
GitHub 저장소를 Vercel에 연결하고 환경 변수 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `GEMINI_API_KEY`, `GEMINI_MODEL`만 넣습니다. `SUPABASE_SECRET_KEY`는 Vercel에 넣지 않습니다.
